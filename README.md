# Starship Light — Omarchy theme

A light Omarchy theme drawn from SpaceX Starship launch photography: sunlit-cloud paper, deep Gulf-sea ink, a steel-blue sky accent, and dusty flame, plume, marsh and smoke tones.

![Starship Light preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/alfarolabs/omarchy-starship-light-theme
```

Or from the desktop: `Super + Alt + Space` → Install → Style → Theme, then paste the URL above.

The theme shows up as **Starship Light** in the theme switcher.

Looking for the dark version? See [Starship](https://github.com/alfarolabs/omarchy-starship-theme).

## Login screen

The theme ships an `unlock.png` for the Plymouth boot / disk-unlock screen:

![Starship Light login screen](preview-unlock.png)

```bash
omarchy plymouth set-by-theme starship-light
```

## Palette

Every color is sampled from a region of one of the four launch photos in `backgrounds/`, and all four photos contribute. Each color keeps its sample's exact hue (in OKLCH). Only the lightness is set so text reads well: every text color is at least 4.5:1 against the background. Saturation is capped, and never more than 2.2x the sample.

The photos have no true red or green, and the palette reflects that. Red is the pink of the Raptor exhaust plume, and green is the olive haze over the Boca Chica marsh at dusk.

| muted | `#babcae` | Dusk liftoff | dusk sky | `#a4a694` |

| yellow | `#875f06` | Starbase plume | sun-gilded plume edge | `#cfab70` |
| orange | `#9c5131` | Tower clear | flame-lit smoke by the tower | `#b68673` |
| green | `#666639` | Dusk liftoff | olive dusk haze over the marsh | `#9fa086` |

The full palette, including bright variants, is in `colors.toml`. Each line there names the photo and region it came from.

Everything else (terminals, Neovim, btop, shell, Hyprland borders, lock screen, VS Code, ...) is generated by Omarchy from `colors.toml`.

Icons: `Yaru-blue`
